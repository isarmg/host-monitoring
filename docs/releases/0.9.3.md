# Host Monitoring 0.9.3

管理 Web 更新：统一导航与实例表格、中英文适配，以及第五行行内登录校验。空字段不会发送登录请求，不再弹出浏览器原生气泡；保留认证、权限边界与当前字体。

修复正式发行验证中的两处问题：

- 发行包校验器允许经过路径、只读权限、大小与 SHA-256 校验的 `web/assets/` WOFF2 字体，同时拒绝篡改与非法路径。
- 解包后启动验证使用当前 `/readyz` 接口，并要求准确的就绪响应，避免旧健康检查地址和 Web 回退页面造成误判。新增就绪、未就绪、错误响应、连接失败及超时回归测试。

`v0.9.1` 与 `v0.9.2` 保留为失败构建的审计标签，没有发布可安装制品；不移动或覆盖标签。本版以 `v0.9.3` 精确提交重新执行完整 CI、不可变发行包校验、解包运行与篡改拒绝验收。
