# Host Monitoring 0.9.2

修复正式 Server 发行包校验器遗漏 WOFF2 字体类型的问题。字体只能位于 `web/assets/`，仍需满足清单路径、只读权限、大小、SHA-256、链接拒绝和总预算校验；不会放行任意文件类型或路径。

新增回归测试验证字体正常发行、内容篡改、非法后缀与错误目录的拒绝行为。

本版同时包含管理 Web 中英文适配、统一导航与实例表格，以及第五行行内登录校验。空字段不会发送登录请求，不再弹出浏览器原生气泡，保留原有字体、认证与权限边界。

`v0.9.1` 标签保留用于审计，其正式打包失败，没有发布可安装制品；不会移动或覆盖该标签。本版以 `v0.9.2` 精确提交重新执行 CI 和正式打包验收。
