# host-monitoring 0.8.0

状态：尚未正式发布。Linux Server/Agent、Web、真实 Collector 以及 Android/iOS 库检查已有通过证据，但 Windows Spool 在 Agent Foundation 私有目录创建时返回 AccessDenied，阻断桌面 Agent 发行。必须修复并验收 Windows 原生文件安全与持久化实现，不能将同步操作改成空操作或跳过失败测试。macOS 测试夹具的非阻塞套接字继承问题已修复，仍以最新 CI 为准。

Server 管理界面采用服务端 Foundation；桌面 Agent、托盘本地管理、移动库采用独立 Agent Foundation。

本次是现有改造工作的阶段收尾，不代表《更新手册》全部完成。不保留旧代码、旧名称或旧版本合同的兼容路径；当前版本部署应使用本版本发行说明和状态合同。
