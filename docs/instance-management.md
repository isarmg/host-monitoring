# 新建实例与配对

管理 Web 只保留「新建实例」入口，不再提供独立的「邀请与配对管理」或「激活配对」入口。

1. 点击「新建实例」，输入实例名称（最多 32 个 Unicode 字符），创建后取得配对码。
2. 配对码不设有效期，仅创建时显示，不放入浏览器持久存储、URL 或日志。请安全保存。
3. 在主机启动 Client 配对，打开 Client 给出的链接，登录后核对设备信息并输入配对码。
4. 绑定成功后配对码不能授权其他设备；Client 确认后开始上报。
5. 未使用的码可在实例配对状态中点击「取消配对」。取消成功后不能恢复或继续使用；丢失配对码也应取消后新建实例。

配对码没有到期字段或定时失效逻辑。设备发起的短期配对请求仍有 15 分钟会话期限以限制未认证请求占用；请求超时不取消配对码，Client 可重新发起请求。此期限不是配对码有效期。

取消与绑定在数据库事务中互斥，已绑定的实例不能按「取消配对」处理；应使用现有设备撤销/删除流程。管理员认证、CSRF、设备确认、单次绑定和审计继续保留。

本次数据结构为 Host Monitoring 0.9.5 / Schema 3。不为旧库保留兼容字段或自动转换；运行中的旧库没有被清空或迁移，升级和恢复仍由 sarmg-upgrade 负责。
